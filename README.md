# KFA AI 에이전트 스터디 포트폴리오

박형민이 KFA 「AI 에이전트 만들기」 스터디에서 실습한 내용과 결과를 기록합니다. 외부 독자가 맥락을 알 수 있도록 주간 기록과 결과물을 함께 정리합니다.

## 에이전트 구조

```mermaid
flowchart LR

	agent -. "사용한 경우 기록" .-> tools["도구 / 모델<br/>확인 후 기입"]
```
