## 작업: 1조 리서치 센터 1단계, 엔진 출력으로 산출물 1·2의 뼈대 만들기

### 전제
- 배포 레포 `KFA-ai-agent-study`의 `docs/plans/engine-step2.md`(공통 엔진 2~4칸)가 끝난 뒤에 시작해. 엔진이 없으면 이 작업은 시작하지 마.
- 산출물 구조는 `research-center/README.md`와 역할 지도 기준. 11/4 1조 모임에서 바뀌면 이 문서부터 고쳐.

### 0. 공통 엔진 코드 가져오기
- 원본은 배포 레포 하나야. 이 레포에는 `engine/`에 **손대지 않은 사본**만 둬: `collect.py`, `engine.py`.
- 사본을 만드는 스크립트 하나(PowerShell)를 만들어: 옆 폴더 `..\KFA-ai-agent-study\tools\`에서 두 파일을 복사하고, 그때의 배포 레포 커밋 해시를 `engine/SOURCE.txt`에 적음.
- 사본을 직접 고치거나 줄인 버전을 만들지 마. 고칠 게 있으면 배포 레포에서 고치고 다시 복사. 두 벌이 생기면 어느 쪽이 맞는지 알 수 없게 돼.
- 엔진 설명은 `docs/engine.md`에 핵심만 있어. 엔진 동작이 바뀌면 그 문서도 같이 고쳐.

### 1. 이 레포 기본 세팅
- `.gitignore`가 없으니 만들어: `.env`, `data/`, `__pycache__/`, `.ipynb_checkpoints/`.
- 키는 배포 레포와 같은 `get_key()`를 씀(엔진 사본에 들어 있음).

### 2. 산출물 1 뼈대 (5쪽만)
- 엔진의 출력 세 가지(지표 표, 주장 대조 표, 출처 목록)만 읽어서 5쪽을 마크다운으로 만듦: 주장 C-1~C-3, 문장 끝 [S#], 근거 지표 값.
- 1~4쪽은 빈 제목만. 2~4쪽은 애널리스트 몫이고 1쪽은 마지막에 씀.
- 산출물 쪽에서 숫자를 새로 계산하지 마. 필요한 숫자가 없으면 엔진 지표 정의 표에 한 줄 추가하자고 나한테 말해줘.

### 3. 산출물 2 ① 숫자 대조
- 엔진의 주장 대조 표를 PASS / REVIEW / FIX 표로 옮김. FIX는 실제 값, REVIEW는 이유를 같이.
- ② 반대신문, ③ 체크리스트, ④ 판단 변화는 이번 범위가 아님 (검증관 역할이 정해진 뒤).

### 4. 실행
- 노트북 `notebooks/research_center_step1.ipynb`: 맨 위 `STOCK_CODE`, `YEAR`만 바꾸면 산출물 1(5쪽)과 산출물 2(①)가 `data/`에 나옴.
- Colab에서 `engine/`을 어떻게 불러올지(레포 clone 후 import, 또는 노트북에 품기)는 계획 단계에서 같이 정하자.
- 주장 하나에 일부러 틀린 숫자를 넣어 FIX가 나오는 것 확인.

### 진행 방식
1. 코드 쓰기 전에 파일 목록과 함수 입력·출력을 계획으로 보여주고 내 확인 받기.
2. 커밋 전에 `git status` 보여주고 `.env`, `data/`가 없는 것 확인. 내 확인 받고 커밋.
